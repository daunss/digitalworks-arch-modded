================================================================================
🛠️ DIGITAL WORKS 3.0 - MODDED EDITION (SISTEM DIGITAL)
================================================================================
Aplikasi simulator gerbang logika Digital Works yang telah dimodifikasi secara 
langsung (in-codebase binary & UI patching) agar lebih cepat, efisien, dan 
nyaman digunakan untuk kegiatan praktikum Sistem Digital.

--------------------------------------------------------------------------------
✨ FITUR UTAMA & KEUNGGULAN MOD
--------------------------------------------------------------------------------
1. ⚡ INSTANT DELETE (Bypass Peringatan Hapus)
   - Tekan tombol "Delete" di keyboard untuk langsung menghapus komponen/kabel.
   - Tidak ada lagi pop-up dialog "Are you sure you want to delete this object?" 
     yang memperlambat kerja.

2. 🔌 SHORTCUT WIRING TOOL CEPAT (Tombol "W")
   - Cukup tekan huruf "W" di keyboard untuk langsung beralih ke mode penarikan 
     kabel (Wiring Tool). Kursor otomatis berubah menjadi alat sambung.
   - Tekan "W" sekali lagi untuk kembali ke kursor panah pemilih biasa.

3. 🌙 CAELESTIA MATCHA DARK MODE (Anti-Silau)
   - Tekan "Ctrl + D" atau buka menu "View -> Dark" untuk mengaktifkan tema 
     gelap elegan yang ramah di mata saat praktikum malam hari.

4. 📊 MENU MODS TERSEMAT LANGSUNG DI HEADER APLIKASI
   - Menu "Mods" tersedia langsung di bar navigasi atas:
     * Auto Truth Table  : Pengecekan tabel kebenaran otomatis
     * Batch Capture     : Screenshot otomatis semua kombinasi input
     * Boolean Equation  : Pembuat persamaan aljabar logika
     * Undo / Redo       : Pembatalan aksi kanvas

5. 📦 PUSTAKA KOMPONEN LENGKAP (IC SERI 74xx & TANENBAUM)
   - Tersedia ratusan IC siap pakai di folder "Parts Centre":
     * Gerbang dasar (7400, 7402, 7404, 7408, 7432, 7486, dsb.)
     * Adder / Subtractor (7483, 74283)
     * Flip-Flop, Multiplexer, Counter, Decoder 7-Segment (7447/7448)
     * Komponen mikroarsitektur Tanenbaum (16-bit ALU, Register File, dll.)
   - Cara pakai: Buka menu "Circuit -> Import", lalu pilih berkas .dwm dari 
     folder "Parts Centre".

--------------------------------------------------------------------------------
🚀 CARA MENJALANKAN
--------------------------------------------------------------------------------
[ PENGGUNA WINDOWS (10 / 11) ]
1. Ekstrak file ZIP ini ke direktori yang diinginkan (misal di Desktop/Documents).
2. Langsung klik dua kali pada file "DigitalWorks.exe" atau "Buka_DigitalWorks.bat".
3. Aplikasi bersifat PORTABLE (tidak memerlukan proses instalasi rumit).

[ PENGGUNA LINUX (Arch / Ubuntu / Mint / Fedora / Debian) ]
1. Pastikan paket "wine" dan "python3" sudah terpasang.
2. Buka terminal di folder ini, lalu jalankan:
      ./digitalworks
   atau
      ./run_linux.sh

--------------------------------------------------------------------------------
⌨️ DAFTAR PINTASAN KEYBOARD (SHORTCUTS)
--------------------------------------------------------------------------------
• W / Ctrl + W : Aktifkan / Nonaktifkan Wiring Tool (Mode Tarik Kabel)
• Delete       : Hapus komponen / kawat terpilih secara instan
• Ctrl + D     : Ganti tema Gelap (Dark Mode) / Terang
• Ctrl + Z     : Undo (Membatalkan perubahan kanvas)
• Ctrl + Y     : Redo (Memajukan perubahan kanvas)
• Ctrl + G     : Tampilkan / Sembunyikan Grid Panduan
• Ctrl + I     : Buka AI Circuit Assistant (Perakit Otomatis)
• F5           : Mulai / Hentikan Simulasi Rangkaian
• Spacebar     : Kirim pulsa Clock Manual (sangat berguna untuk Flip-Flop)
